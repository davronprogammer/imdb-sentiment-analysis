# Frontend Web Showcase Directory

This directory is reserved for the future static educational portfolio website demonstrating the IMDB Sentiment Analysis project.

## Implementation Architecture (Planned Phase 2)
- **Stack**: Pure client-side static application using standard HTML5, CSS3, and vanilla JavaScript (ES6+).
- **Backend**: Zero backend required (100% static hosting compatible with Netlify, Vercel, or GitHub Pages).
- **Inference Strategy**: Client-side execution via ONNX WebAssembly (`onnxruntime-web`) or visual interactive exploration using precomputed test metrics and sample evaluations.
